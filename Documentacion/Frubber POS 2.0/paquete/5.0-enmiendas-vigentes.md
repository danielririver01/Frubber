# 5.0 Enmiendas vigentes del Movimiento 2

Versión 2.0 · 19 de noviembre de 2026

La lista de 38 enmiendas aprobadas en AC-01 se aplica en las siete revisiones 2.0. AC-07 fija la redacción de V-1 y A-2. AC-08 determina la impresora por puesto. AD-01 y AD-02 sustituyen las doce redacciones de la tabla y retiran A-4. AD-07 elimina el requisito de congelar la 1.0.

| Enmienda | Texto vigente |
| --- | --- |
| A-1 | ADR-004 admite PostgreSQL como motor local del equipo servidor. |
| A-4 | Retirada. La verificación usa la firma y DPAPI protege las credenciales de puestos. |
| A-5 | SQLite con WAL se conserva para 1.0. La 2.0 conecta los puestos a PostgreSQL por la LAN con un rol propio. |
| A-6 | Instalación de servidor y puesto. Solo el servidor migra y el puesto desactualizado debe actualizarse. |
| A-7 | ADR-021 y 024 retiradas. ADR-022, 023 y 025 a 030 vigentes. La Arquitectura Técnica documenta el contrato real FRB1 y FRB2 con ECDSA y Base64. |
| B-1 | Línea base nueva en PostgreSQL, con puesto, índice parcial de caja abierta y UUID único de solicitud. |
| B-3 | Respaldo programado en el servidor con pg_dump y restauración con pg_restore. |
| S-1 | Servidor PostgreSQL y puestos conectados por la LAN sin necesidad de internet. |
| S-3 | Rol por puesto, DPAPI para su credencial, PIN por función SECURITY DEFINER y TLS VerifyFull. |
| S-4 | Licencia firmada, ligada al servidor. FRB1 cubre una caja. FRB2 usa su cupo firmado. Soporte busca la FRB1 en el historial y el dueño puede reemitirla para el mismo equipo si falta. |
| T-1 | Npgsql, conexión agrupada y reconexión. |
| T-4 | Concurrencia, corte del cobro, numeración, restauración y caída del motor. |
| U-2 | Mensajes de servidor, autorización del puesto, actualización y cupo. |
