# JHO-121 · Instalador Caja principal

Entregar un paquete Windows x64 que funcione sin conexión y contenga PostgreSQL 18.7, versión aprobada el 19 de noviembre de 2026. Preparar el esquema 2.0 y el primer puesto, registrar el servicio automático y el respaldo diario, y limitar la conexión de las cajas a la subred local usando TLS y SCRAM.
